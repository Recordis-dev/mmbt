# V1.1 Implementation Plan

## Phase 1: Operable MVP

- Telegram webhook receives raw signal text.
- Token parser extracts the first Solana address.
- Admission control rejects duplicates, daily limit breaches and circuit breaker state.
- RugCheck, GoPlus and SolSniffer run in parallel.
- Jupiter quote and swap transaction are generated.
- Signer is left as a secure boundary.
- Position is inserted into PostgreSQL after buy confirmation.

## Phase 2: Defensive Runtime

- Monitor loop evaluates positions every 5 seconds.
- Local risk engine detects volume decline, holder drop, sell pressure spike and fee congestion.
- Exit engine handles panic exit, hard stop, partial 2x take profit and trailing stop.
- Health check activates the circuit breaker and closes open positions when limits are breached.
- Startup recovery resumes or closes stale positions.

## Phase 3: Intelligence Layer

- Claude analyzes semantic market context only when available.
- Local engine remains authoritative fallback.
- Decision logs capture source as `claude`, `local_engine` or `manual`.
- Dashboard consumes `system_state`, `positions` and `decision_logs`.

## Paper Mode Checklist

- Security checks reject known bad tokens.
- Security checks abort when only 1 provider responds.
- Duplicate cache suppresses repeated token signals.
- Daily trade count stops at 200.
- Open-position cap queues the 4th token.
- Hard stop triggers at 34% of entry.
- Partial take profit triggers once at 2x.
- Trailing stop tightens after 2x and caps at 55%.
- Circuit breaker activates at `-$15` daily PnL or 15 consecutive losses.
